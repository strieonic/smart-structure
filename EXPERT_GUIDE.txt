3. API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════

AUTHENTICATION
--------------
POST   /api/v1/auth/register-expert    Register new expert
POST   /api/v1/auth/login               Login (user or expert)

EXPERT MANAGEMENT
-----------------
GET    /api/v1/experts                  Get all verified experts (public)
GET    /api/v1/experts/:id              Get expert profile (public)
GET    /api/v1/experts/dashboard/stats  Get expert dashboard (protected)
PUT    /api/v1/experts/profile          Update expert profile (protected)

QUERY MANAGEMENT
----------------
GET    /api/v1/experts/queries/all      Get expert's queries (protected)
POST   /api/v1/experts/queries          Create new query (protected)
POST   /api/v1/experts/queries/:id/assign    Assign query to self (protected)
POST   /api/v1/experts/queries/:id/respond   Respond to query (protected)

4. DATABASE SCHEMA
═══════════════════════════════════════════════════════════════════════════

ExpertProfile
-------------
- id: String (UUID)
- userId: String (FK to User)
- expertType: ExpertType enum
- licenseNumber: String
- experience: String
- location: String
- phone: String
- specializations: Json (Array)
- summary: String (optional)
- status: ExpertStatus (PENDING, VERIFIED, SUSPENDED)
- verifiedAt: DateTime
- portfolioData: Json (optional)

ExpertQuery
-----------
- id: String (UUID)
- userId: String (FK to User)
- expertId: String (FK to ExpertProfile, nullable)
- title: String
- description: String
- category: String
- priority: String (LOW, MEDIUM, HIGH, URGENT)
- projectId: String (optional)
- status: String (OPEN, ASSIGNED, IN_PROGRESS, RESOLVED, CLOSED)
- expertResponse: String (optional)
- responseAt: DateTime (optional)
- attachments: Json (optional)

7. USER WORKFLOWS
═══════════════════════════════════════════════════════════════════════════

A. EXPERT REGISTRATION WORKFLOW
   1. Navigate to Authentication section
   2. Select "Expert Account" type
   3. Click "Expert Register" tab
   4. Fill Step 1: Basic Information → Next
   5. Fill Step 2: Professional Details → Next
   6. Fill Step 3: Specializations → Register
   7. Auto-login and redirect to Expert Dashboard

B. EXPERT LOGIN WORKFLOW
   1. Navigate to Authentication section
   2. Select "Expert Account" type
   3. Click "Expert Login" tab
   4. Enter credentials → Login
   5. Redirect to Expert Dashboard

C. USER POSTS QUERY WORKFLOW
   1. Login as regular user
   2. Navigate to Professional Network
   3. Click "Post Query" button
   4. Fill query details
   5. Optionally select preferred expert
   6. Submit query

D. EXPERT RESPONDS TO QUERY WORKFLOW
   1. Login as expert
   2. Navigate to Expert Dashboard
   3. View pending queries
   4. Click "Accept Query" to assign to self
   5. Click "Respond" to submit response
   6. Query status changes to RESOLVED
