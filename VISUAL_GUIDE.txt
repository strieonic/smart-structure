8. INTERACTION FLOW
═══════════════════════════════════════════════════════════════

Normal Usage:
1. Open http://localhost:8080
2. Use site normally (no interruptions)
3. Status indicator hidden
4. No notifications

When Error Occurs:
1. Error detected (within 1 minute)
2. Notification appears (top-right)
3. Status indicator appears (bottom-right)
4. AI analyzes error
5. Auto-fix attempted
6. Success notification shown
7. Status indicator disappears

Checking System Status:
1. Click ☰ button (top-right)
2. View Site Status tab
3. See real-time status
4. Check for issues
5. Read AI suggestions
6. Refresh if needed

Accessing Settings:
1. Click ☰ button (top-right)
2. Click Settings tab
3. Quick login/register
4. Adjust preferences
5. View system info
