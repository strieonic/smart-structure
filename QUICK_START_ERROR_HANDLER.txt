✅ WHAT IT DOES AUTOMATICALLY
═══════════════════════════════════════════════════════════

   ✓ Starts backend (port 5000) if not running
   ✓ Starts frontend (port 8080) if not running
   ✓ Monitors servers every 10 seconds
   ✓ Auto-restarts crashed servers
   ✓ Fixes port conflicts
   ✓ Installs missing dependencies
   ✓ Runs database migrations
   ✓ Uses AI for complex errors
   ✓ Shows notifications in browser

═══════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════
🔧 COMMON ERRORS & AUTO-FIXES
═══════════════════════════════════════════════════════════

   ERROR                    AUTO-FIX
   ─────────────────────────────────────────────────────────
   Backend down          → Auto-starts backend
   Frontend down         → Auto-starts frontend
   Port 5000 in use      → Kills process, restarts
   Port 8080 in use      → Kills process, restarts
   Missing dependencies  → Runs npm install
   Database migration    → Runs prisma migrate
   Python not found      → Shows installation guide
   Unknown error         → Consults AI for solution

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════

   Problem: Notifications not showing
   Solution: Check http://localhost:9999/status
            Clear browser cache and reload

   Problem: Servers not auto-starting
   Solution: Check logs/error-handler.log
            Verify npm and python are in PATH

   Problem: Port 9999 in use
   Solution: netstat -ano | findstr :9999
            taskkill /F /PID <PID>
