   ✓ Determine if auto-fixable

═══════════════════════════════════════════════════════════
🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════

   Menu Button Not Showing:
   • Refresh page (Ctrl+F5)
   • Check if system-menu.js loaded
   • Clear browser cache

   Status Not Updating:
   • Click "Refresh Status" button
   • Check if error handler is running
   • Verify port 9999 is accessible

   Notifications Not Appearing:
   • Check Settings → Enable notifications
   • Look in Site Status for all notifications
   • Check browser console for errors
